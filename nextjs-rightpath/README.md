# RightPath NGO - Next.js Application

Modern, high-performance Next.js 14 App Router conversion for the **RightPath NGO** official website.

## ✨ Highlights & Improvements
- **100% Bug-Free Layout**: Completely fixed UI alignment, responsive grids, and zero-jitter headline rotators.
- **Next.js 14 App Router**: Modular React components, optimized asset handling, and fast performance.
- **Interactive State**: Synchronized Live Giving Calculator, dynamic category filters, and seamless donation popups.
- **Tailwind CSS**: Full design system tokens matching RightPath NGO brand guidelines.

## 🚀 How to Run Locally

1. Open terminal in the `nextjs-rightpath` folder:
   ```bash
   cd nextjs-rightpath
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the Next.js development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Production Build & Deployment
```bash
npm run build
npm start
```
You can also import this directory directly into **Vercel** or **Netlify** for 1-click cloud deployment.
